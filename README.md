## 단계별 설명

### 1. 영상 정리 (`organize.py`)

파일명 규칙을 파악하여 채널별, 날짜별로 자동 분류한다.

**파일명 형식**
```
XVR_ch{N}_main_YYYYMMDDHHMMSS_YYYYMMDDHHMMSS.mp4
```

| 필드 | 설명 |
|---|---|
| `XVR` | 녹화 장비명 |
| `ch{N}` | CCTV 채널 번호 |
| `main` | 메인 스트림 |
| `YYYYMMDDHHMMSS` | 시작 시각 |
| `YYYYMMDDHHMMSS` | 종료 시각 |

**결과 폴더 구조**
```
cctv1/
├── ch1/
│   └── 10/   ← DD (날짜)
│       └── XVR_ch1_main_....mp4
├── ch3/
└── ch6/
```

---

### 2. 영상 병합 (`merge.py`)

채널 + 날짜 조합 단위로 클립들을 하나의 영상으로 합산한다.

- `ffmpeg concat` 방식 사용 (`-c copy`, 재인코딩 없음)
- 클립은 파일명(시작 시각) 기준으로 정렬 후 병합
- 결과: `merged/` 폴더에 13개 영상 저장

| 그룹 | 클립 수 |
|---|---|
| ch1_10 | 60개 |
| ch1_11 | 104개 |
| ch3_10 | 345개 |
| ch7_10 | 1024개 |
| ... | ... |

---

### 3. 얼굴 모자이크 (`face_mosaic.py`)

개인정보 보호를 위해 영상 내 모든 얼굴에 모자이크를 적용한다.  
**이후 모든 분석은 모자이크 처리된 영상(`mosaic/`)을 사용한다.**

- **모델**: YOLOv8-Face (`yolov8n-face.pt`, HuggingFace 자동 다운로드)
- **가속**: CUDA (RTX 5070 Ti)
- **처리 방식**: BATCH_SIZE=4 병렬 처리
- **모자이크**: 픽셀화 방식 (`MOSAIC_SCALE=0.05`)

| 설정값 | 기본값 | 설명 |
|---|---|---|
| `CONF_THRESHOLD` | 0.5 | 얼굴 검출 신뢰도 |
| `MOSAIC_SCALE` | 0.05 | 모자이크 강도 (낮을수록 강함) |
| `PADDING` | 0.15 | 얼굴 박스 여백 비율 |

---

### 4. 매대 구역 설정 (`zone_config.py`)

영상 첫 프레임을 GUI로 띄워 마우스로 매대 구역을 지정한다.

```bash
python zone_config.py --camera ch3
```

**조작 방법**

| 키 | 동작 |
|---|---|
| 마우스 클릭 | 꼭짓점 추가 |
| `E` | 현재 구역 완료 → 구역명/상품 입력 |
| `U` | 마지막 꼭짓점 취소 |
| `D` | 마지막 구역 삭제 |
| `Q` | 저장 후 종료 |

입력 예시:
```
구역명: 과자코너
상품 목록: 새우깡, 포카칩, 프링글스
```

결과는 `zones.json`에 저장된다.

---

### 5. 영상 분석 (`analyze.py`)

모자이크 영상을 분석하여 방문자별 행동 데이터를 추출한다.

#### 카메라별 역할

| 카메라 | 역할 |
|---|---|
| ch3, ch6 | 인물 추적, 구역 체류, 성별/나이 분류 |
| ch1 | 계산대 구매 행동 감지 |

#### 분석 흐름

```
Step 1  ch3, ch6 각각 YOLO 추적 + 외모 임베딩 추출
Step 2  ch3 ↔ ch6 임베딩 코사인 거리 매칭
            → 같은 사람 = 같은 글로벌 방문자 ID
Step 3  ch1 YOLO 추적 + 임베딩 추출
Step 4  ch1 ↔ ch3/ch6 임베딩 매칭
            → 구매 여부를 글로벌 ID에 연결
Step 5  결과 합산 → visit_data.json 저장
```

#### Cross-camera Re-ID

- **방법**: MobileNetV3 외모 임베딩 + 코사인 거리
- 얼굴이 모자이크되어 있으므로 **하체(하위 75%) 중심**으로 특징 추출
- `REID_THRESHOLD = 0.45` (낮을수록 매칭 엄격)

#### 성별 분류

- 모자이크 상태이므로 **전신 체형 및 의상** 기반 분류
- MobileNetV3 2-class 분류기 사용

#### 성인/비성인 분류

카메라 스펙을 활용한 원근 보정 공식 적용:

```
발 위치(y좌표) → 지면 거리 역산 → 해당 거리에서 1.5m가 차지할 픽셀 비율 계산
→ 실제 바운딩박스 높이와 비교
```

| 카메라 스펙 | 값 |
|---|---|
| 설치 높이 | 2.2m |
| 앙각 | 35° |
| 수직 화각 | 40° |
| 성인 최소 신장 기준 | 1.5m |

#### 실시간 미리보기

분석 중 시각화 창이 표시된다.

| 표시 요소 | 내용 |
|---|---|
| 구역 폴리곤 | 반투명 색상으로 매대 표시 |
| 인물 박스 | 파랑=남성 / 분홍=여성 / 빨강=구매 / 회색=미확인 |
| 박스 라벨 | 글로벌 ID, 성별, 성인 여부 |
| 체류 시간 | 현재 머무는 매대명 + 경과 시간(초) |
| 상단 HUD | 카메라명, 진행률, 현재/누적 인원 |

`Q` 키를 누르면 현재 영상을 건너뛰고 다음 카메라로 이동한다.

#### 주요 설정값

| 변수 | 기본값 | 설명 |
|---|---|---|
| `REID_THRESHOLD` | 0.45 | Re-ID 매칭 임계값 |
| `DWELL_MIN_SEC` | 3.0 | 최소 체류 인정 시간 (초) |
| `PURCHASE_DWELL_SEC` | 5.0 | 구매 판정 최소 체류 시간 (초) |
| `EMBED_INTERVAL` | 10 | 임베딩 추출 간격 (프레임) |
| `DISPLAY_SCALE` | 0.5 | 미리보기 창 축소 비율 |

---

### 6. 결과 출력 (`export.py`)

`visit_data.json`을 읽어 터미널 요약 테이블과 CSV 파일을 생성한다.

#### 터미널 출력 테이블

**테이블 1 — 개인별 방문 상세**

| 컬럼 | 설명 |
|---|---|
| 에이전트ID | 글로벌 방문자 ID |
| 고객분류 | 성별_연령 조합 코드 |
| 고객분류명 | 예: 남성 성인 |
| 방문구역 | 방문한 매대 목록 |
| 상품명 | 구매 물품 |
| 총체류시간 | 전체 매대 체류 합산 |
| 일차(카메라) | 감지된 카메라 |
| 시간대 | 방문 시간대 |

**테이블 2 — 고객 분류별 요약**

| 컬럼 | 설명 |
|---|---|
| 분류명 | 성별+연령 분류 |
| 방문객수 | 해당 분류 총 인원 |
| 구매고객수 | 구매한 인원 |
| 구매전환율 | 구매고객수 / 방문객수 |
| 평균체류시간 | 분류별 평균 매장 체류 |

**테이블 3 — 구역별 분석**

| 컬럼 | 설명 |
|---|---|
| 구역 | 매대명 |
| 방문객수 | 해당 구역 방문 인원 |
| 구매고객수 | 구매로 이어진 인원 |
| 구매전환율 | 구매고객수 / 방문객수 |
| 평균체류시간 | 구역별 평균 체류 |
| 구매/비구매 체류 | 구매자 vs 비구매자 총 체류 비교 |
| 비효율지수 | 체류 길지만 구매 안 한 정도 |

#### CSV 출력 파일

| 파일명 | 내용 |
|---|---|
| `visit_report.csv` | 개인별 전체 방문 데이터 |
| `visit_summary.csv` | 매대별 요약 |
| `visit_demo.csv` | 인구통계 (성별/연령) |

> 인코딩: `utf-8-sig` (엑셀에서 한글 깨짐 없이 바로 열기 가능)

## 주요 기술 스택

| 항목 | 내용 |
|---|---|
| 인물 추적 | YOLOv8n + ByteTrack |
| 얼굴 감지 | YOLOv8-Face |
| Cross-camera Re-ID | MobileNetV3 임베딩 + 코사인 거리 |
| 성별 분류 | MobileNetV3 (전신 기반) |
| 성인/비성인 분류 | 원근 보정 기하학 공식 |
| GPU 가속 | CUDA (NVIDIA GeForce RTX 5070 Ti) |
| 출력 | CSV (pandas) |

## 1. 전체 모델 구성

본 프로젝트에서 딥러닝 모델은 **역할에 따라 두 가지로 분담**된다.

| 역할 | 모델 | 예측 대상 |
|------|------|-----------|
| 구역·시간대 구매수 예측 | **Transformer** | KPI #1 (구역별 구매전환율), KPI #6 (시간대별 구매전환율) |
| 5종 KPI 동시 예측 | **Crossformer** | KPI #2 전환율, #3 체류시간, #5 고객군 구매수, #7 전환효율, #8 비효율구역 |
| 비교 대조군 | **LSTM** | 셀별 구매비중 (타깃 설계 한계로 비효율) |

### 데이터 분할

```
전체 120일
  ├── Train  : 1  ~ 84일  (70%)
  ├── Val    : 85 ~ 104일 (17%)
  └── Test   : 105 ~ 120일 (13%) ← 성능 측정 기준
```

## 2. Transformer — PurchaseGridTransformer

### 핵심 아이디어

매장을 **7개 구역 × 12개 시간대 = 84개 셀의 격자**로 추상화하고,  
각 셀의 구매 수를 동시에 예측하는 **SpaceTime Attention** 구조.

```
Input: [Batch, L=7일, N=84 tokens, F=8 features]
         ↓
  Zone Emb  [7 × d=96]
  Hour Emb  [12 × d=96]    → 합산 후 Projection
  DoW Emb   [7 × d=96]
  Pos Emb   [L × d=96]
         ↓
  SpaceTimeBlock × 3
    ├── Spatial Attention  (구역 간 상관 포착)
    ├── Temporal Attention (시간 패턴 포착)
    └── FFN
         ↓
  LayerNorm → Linear(d=96 → 1)
         ↓
Output: [Batch, H=1, N=84]  (log1p 공간 → 역변환)
```

### 하이퍼파라미터

| 항목 | 값 |
|------|----|
| d_model | 96 |
| n_heads | 4 |
| n_layers | 3 |
| dropout | 0.1 |
| 최적화기 | AdamW (weight_decay=0.01) |
| 학습률 | 0.001 (Cosine + warmup 5 epoch) |
| 손실함수 | SmoothL1 (β=0.5) |
| 조기종료 epoch | **16** / 최대 200 |

### 성능 (Test set, 16일)

| 지표 | 값 | 비고 |
|------|----|------|
| 셀 MAE | **2.45** | Baseline 3.55 대비 **+31.0% 개선** |
| 구역 집계 MAE | 4.20 | |
| 구역 집계 MAPE | **4.0%** | 실무 기준 10% 이하 ✅ |
| 구역 Spearman ρ | **1.000** | 7개 구역 순위 완벽 재현 |
| 시간대 집계 MAE | 2.94 | |
| 시간대 집계 MAPE | **5.4%** | 실무 기준 10% 이하 ✅ |
| 시간대 Spearman ρ | **0.972** | |

### v1 → v2 개선 내역

| 지표 | v1 (개선 전) | v2 (개선 후) | 변화 |
|------|------------|------------|------|
| 셀 MAE | 3.58 | **2.45** | −31.6% |
| 구역 MAE | 24.73 | **4.20** | −83.0% |
| 시간대 MAE | 11.76 | **2.94** | −75.0% |
| 구역 ρ | 0.500 | **1.000** | ↑ |
| 시간대 ρ | −0.462 | **0.972** | ↑↑ |

**v2 적용 기법**: log1p 타깃 정규화 · 분리 임베딩(zone/hour/dow/pos) · SmoothL1 손실 · 조기종료

## 3. Crossformer — KPI Crossformer

### 핵심 아이디어

시간 차원과 변수 차원을 **Two-Stage Attention**으로 분리 학습.  
단일 모델로 **5가지 KPI를 동시에** 예측하는 멀티태스크 구조.

```
Input: [Batch, L=5일, Z×T×C tokens, F=4 features]
         ↓
  TwoStageAttentionLayer × 2
    ├── Stage 1: Time Attention       (시간 축 패턴)
    └── Stage 2: Router Cross-Dim Attn (변수 간 상관, n_router=8)
         ↓
  Purchase Head  →  구매수 예측
  Dwell Head     →  체류시간 예측
         ↓
Output (5 KPIs):
  KPI #2 전체 구매전환율
  KPI #3 구역별 체류시간
  KPI #5 고객군별 구매수
  KPI #7 체류 대비 전환효율
  KPI #8 비효율 구역 지수
```

### 하이퍼파라미터

| 항목 | 값 |
|------|----|
| d_model | 64 |
| n_heads | 4 |
| n_layers | 2 |
| n_router | 8 |
| 손실함수 | SmoothL1 |
| Best Val Loss | **0.4533** |
| 조기종료 epoch | **88** / 최대 200 |

### 성능 (KPI별)

| KPI | 지표 | 값 |
|-----|------|----|
| KPI #2 전체 구매전환율 | MAPE | 14.0% |
| KPI #3 구역별 체류시간 | MAPE | **8.6%** |
| KPI #3 구역별 체류시간 | Spearman ρ | **0.964** |
| KPI #5 고객군별 구매수 | MAPE | 19.1% |
| KPI #5 고객군별 구매수 | Spearman ρ | **1.000** |
| KPI #7 체류 대비 전환효율 | MAPE | **3.9%** |
| KPI #7 체류 대비 전환효율 | Spearman ρ | **0.964** |
| KPI #8 비효율 구역 지수 | Spearman ρ | **0.918** |

### 비효율 구역 Top 3 예측 결과 (KPI #8)

| 순위 | 구역 | 비효율 지수 |
|------|------|------------|
| 1위 | 과자/스낵 | 0.440 |
| 2위 | 프리미엄 | 0.258 |
| 3위 | 냉동식품 | 0.197 |

> **비효율 지수** = 체류시간 비율 × (1 − 전환율 비율)  
> 높을수록 오래 머물지만 구매로 이어지지 않는 구역 → 상품 재배치 또는 프로모션 우선 대상

## 7. 결론 및 발표 핵심 요약

### 한 줄 결론

> **"구역·시간대 순위 예측 97~100%, 집계 오차 4~5%, Baseline 대비 +31%"**

### 모델별 역할 분담 요약

- **Transformer**: 구매수 격자 예측 특화 → 구역별·시간대별 전환율 KPI 담당  
- **Crossformer**: 멀티타깃 KPI 예측 특화 → 체류시간·전환효율·비효율구역 동시 예측  
- **LSTM**: 타깃 설계 한계로 대조군 역할 → Transformer/Crossformer의 설계 우수성 부각

### 포스터 강조 포인트 (추천)

1. **구역 Spearman ρ = 1.000** — 7개 구역의 구매 순위를 완벽하게 예측
2. **Transformer MAPE 4.0~5.4%** — 실무 사용 가능 기준(10%)의 절반 이하
3. **v1 → v2 구역 MAE −83%** — 아키텍처 개선의 극적인 효과
4. **Crossformer 비효율 구역 ρ 0.918** — 상품 재배치 대상 구역을 정확히 식별
5. **Baseline 대비 +31%** — 단순 예측 대비 딥러닝의 실질적 우위 입증
